# Code Club

A five-page static website for the Code Club at upGrad School of Technology. Built with semantic HTML and one shared stylesheet, with no JavaScript or frameworks.

## Pages

- `index.html` — Home
- `events.html` — Upcoming and past events
- `team.html` — Club team
- `gallery.html` — Club gallery
- `contact.html` — Contact form and FAQs

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server. All provided images live in `images/` and are linked with relative paths.

## Project status

GitHub repository, pull requests, proof screenshots, and GitHub Pages deployment are not configured in this local workspace yet.

The contact address shown in the design is an example address. Replace it with the club's real email before publishing so the contact form reaches the right place.
